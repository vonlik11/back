# Маркетолог° — Telegram Mini App

Интерактивный макет Mini App по ТЗ **«Автономный AI-маркетолог для бизнеса»**. Интерфейс оформлен в фирменной бирюзово-синей палитре «Салаватстекло»: боковая навигация, карточка компании и статусы контента.

## Как открыть

1. Установите Python 3 и Node.js 18 или новее.
2. Запустите сайт из папки проекта:
   ```bash
   python main.py
   ```
3. Откройте `http://localhost:3000`. Не открывайте `index.html` как `file://`: API синхронизации работает через сервер.

---

## Что внутри макета

### 1. Экран входа и регистрации
- Вход по email и паролю через Firebase Authentication.
- Форма регистрации создаёт Firebase-аккаунт по имени, email и паролю.
- ChatGPT подключается отдельно после входа и не создаёт фиктивный аккаунт.

### 2. Пять вкладок без чата
Чат полностью убран — управление построено на карточках, расписании и нижних шторках (sheets):
- **Обзор:** статус агента (работает / на паузе), время ближайшей публикации, карусель постов на согласовании, сводка недели и быстрые действия («Новый пост», «Добавить в расписание», «Контент-план на неделю»).
- **Контент:** фильтр по статусам (*Все, На согласовании, Одобрено, Опубликовано, Черновики*), пакетное одобрение в один тап и **Умная карточка согласования** (переключение текста под Telegram / VK / MAX, выбор из 3 заголовков, обложка с чистой кириллицей, привязка к фактам `F-102`, проверки бренда и ФЗ «О рекламе», внесение правок с созданием `v2`, перенос времени, отзыв публикации).
- **Расписание (конструктор):**
  - Тумблер автопостинга 24/7 и календарная полоса недели с индикаторами слотов.
  - **Собственное расписание (`+` / «Новый слот»):** выбор названия, любых дней недели (вручную или пресетами *Будни / Каждый день / Выходные*), **нескольких времён публикации в день**, рубрики, площадок, режима (*С согласованием / Автоматически*) и повтора (*Каждую неделю / Один раз*).
  - Готовые шаблоны расписания и календарь отраслевых инфоповодов.
- **Аналитика:** переключатель *7 / 30 дней*, график охвата, метрики (ER, переходы, заявки, расход ИИ), разбор лучшего и худшего поста, A/B-эксперимент заголовков, радар конкурентов и триаж комментариев.
- **Профиль:** аккаунт, статус и пинг ChatGPT, переключение компаний и **5-шаговый мастер подключения новой компании без кода**, уровни автономности `L0–L3`, проверка каналов, навыки агента, бюджет, живая проверка изоляции данных (RLS) и табло приёмки на 12 критериев ТЗ.

### Новый интерфейс и компании
- В боковой панели доступны разделы, список компаний и кнопка **«Новая компания»**.
- Мастер добавления сохраняет название, сферу, сайт и созданное расписание в `localStorage`; после перезагрузки компания остаётся на этом устройстве.
- В обзоре показываются счётчики публикаций и галерея примеров: истории сотрудников, новости/достижения и корпоративные события. Нажатие на пример открывает форму черновика с соответствующим направлением текста.
- Примеры изображений находятся в `assets/post-examples/`, логотип с исходного бренд-скриншота — `assets/salavat-logo.png`.

### Серверная синхронизация компаний
- `server.js` раздаёт Mini App и предоставляет `GET/PUT /api/companies`.
- API проверяет Firebase ID token и разделяет данные по UID пользователя. Вход через демо-кнопки Telegram/ChatGPT не является проверенным аккаунтом и остаётся локальным.
- Данные лежат в `.mark-ai-data/companies.json` (папка исключена из Git). Для постоянного хранения на хостинге укажите `DATA_DIR` на постоянный диск; `FIREBASE_PROJECT_ID` задаёт Firebase project ID и по умолчанию равен `petmatch-2d396`.
- При первом email-входе локальный список отправляется на сервер, если для аккаунта ещё нет сохранённого списка. При последующих входах серверная версия становится основной.

Каналы, загрузка базы знаний и генерация публикаций всё ещё требуют отдельной серверной интеграции.
