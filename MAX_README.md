# MAX-бот AI-маркетолога

MAX-адаптер использует профиль и MAX user ID каждого пользователя отдельно. Он принимает задачу, готовит текст и иллюстрацию, показывает черновик и публикует его в подключённый канал только после одобрения.

## Запуск

1. Создайте бота на платформе MAX для бизнеса и добавьте `MAX_BOT_TOKEN` в `.env`.
2. Установите Python 3.10+ и Node.js 22.12+. Для часовых поясов в Windows выполните `py -3 -m pip install tzdata`; в папке проекта выполните `npm install`.
3. Запустите `py -3 max_main.py` и оставьте терминал открытым.
4. В MAX откройте бота и отправьте `/start`. Укажите название и описание компании, затем подключите ChatGPT через кнопку или выберите API командой `/api`.
5. Добавьте бота администратором своего MAX-канала с правом публикации. Он привяжет канал по событию MAX.
6. Отправьте тему поста. Проверьте черновик и нажмите **«Одобрить и опубликовать»**. Для правок ответьте `переделай: пожелание`.

## Функции

- Главное меню: создание поста, профиль, история публикаций, расписание и помощь.
- Профиль компании, канал и черновики хранятся отдельно по MAX user ID. `/company` меняет профиль; `/channel` показывает статус подключения. Если авто-подключение не сработало, используйте `/channel <числовой ID>` после добавления бота администратором.
- Вход ChatGPT через OpenAI Sign in with ChatGPT, данные хранятся отдельно в `.auth/max/<MAX user ID>`.
- `/api` подключает OpenAI, Gemini, Claude или DeepSeek. Ключ вводится в локальной форме `127.0.0.1` на компьютере, где запущен бот; ключ не отправляется в MAX. Допустим и вариант `/api gemini` (вместо `gemini` — `openai`, `claude` или `deepseek`).
- Для поста автоматически ищется тематическое фото Wikimedia Commons с лицензией CC0 или Public Domain. Добавьте «только текст» или «без картинки», чтобы пропустить поиск. Можно прислать своё изображение вместе с задачей, использовать `/findimage описание` или `/image описание`.
- Черновик можно одобрить, отклонить, изменить текст, заменить фото или убрать иллюстрацию. Сбой с неоднозначным результатом публикации переводит черновик в `needs_review`; сначала проверьте канал вручную.
- `/schedule 09:00` готовит один черновик в день по часовому поясу `TIMEZONE`; `/schedule off` выключает расписание. Публикация никогда не происходит автоматически.
- `/analytics` показывает локальную историю публикаций; `/status` показывает ожидающий черновик; `/reset` запрашивает подтверждение и сбрасывает профиль и вход.
- Лимиты по умолчанию: 30 текстовых AI-запросов в день для всех пользователей и 5 на пользователя; для генерации изображений — 10 для всех и 3 на пользователя. Значения настраиваются в `.env`.

## Настройки `.env`

- `MAX_BOT_TOKEN` — обязательный токен MAX-бота.
- `TIMEZONE` — часовой пояс расписания, например `Asia/Yekaterinburg`.
- `OPENAI_API_KEY` — необязательный ключ API для генерации новых изображений. Поиск фото и текстовые посты работают без него.
- `OPENAI_API_MODEL`, `GEMINI_MODEL`, `CLAUDE_MODEL`, `DEEPSEEK_MODEL` — имена моделей для выбранного текстового API.
- `DAILY_AI_LIMIT`, `DAILY_USER_LIMIT`, `DAILY_IMAGE_LIMIT`, `DAILY_USER_IMAGE_LIMIT` — дневные лимиты.

Не отправляйте API-ключ сообщением в MAX: бот подскажет открыть локальную форму и ввести его на компьютере с запущенным ботом. Чат в MAX не используется для передачи секрета.

## Доступ и ограничения

- Состояние хранится локально в `max_state.json`; OAuth-файлы — в `.auth/max`. Эти файлы не включаются в дистрибутив.
- Отчёт `/analytics` ведёт собственный список постов, опубликованных текущей версией адаптера. Реакции и просмотры здесь пока не собираются.
- Long Poll подходит для локального демо. Для постоянного публичного сервиса настройте HTTPS Webhook.
- Для фото MAX использует `POST /uploads`, а затем `POST /messages`; изображение отправляется вложением с upload token. [Документация MAX по загрузке медиа](https://dev.max.ru/docs-api/methods/POST/uploads), [отправке сообщений](https://dev.max.ru/docs-api/methods/POST/messages).
