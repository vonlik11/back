# VK-бот AI-маркетолога

VK-адаптер использует профиль одного администратора, указанного через `VK_ADMIN_USER_ID`. Он готовит черновик, показывает его в личных сообщениях и публикует на стене сообщества только после явного одобрения.

## Запуск

1. В `.env` задайте `VK_GROUP_TOKEN`, `VK_GROUP_ID` и `VK_ADMIN_USER_ID`. Пример настроек есть в `.env.example`.
2. В Windows установите базу часовых поясов: `py -3 -m pip install tzdata`. Для доступа ChatGPT установите Node.js 22.12+ и выполните в папке проекта `npm install`.
3. Включите сообщения сообщества и Bots Long Poll; в событиях Long Poll включите `message_new`. Выдайте токену сообщества разрешения на сообщения, фотографии и публикацию на стене.
4. Запустите `py -3 -u vk_main.py` и оставьте терминал открытым.
5. Напишите сообществу `/start`, настройте профиль, подключите ChatGPT командой `/chatgpt` или текстовый API командой `/api`, затем отправьте тему публикации.

## Команды

- `/post` — начать подготовку поста; текст можно также отправить обычным сообщением.
- `/profile` — посмотреть профиль; `/company` — изменить его.
- `/chatgpt` — подключить ChatGPT отдельной ссылкой авторизации.
- `/api` — выбрать OpenAI, Gemini, Claude или DeepSeek API. Можно сразу написать `/api gemini` (или `openai`, `claude`, `deepseek`). Ключ вводится в локальной форме на компьютере с ботом и не отправляется в VK.
- `/approve` и `/reject` — опубликовать или отклонить черновик.
- `/edit текст` или `переделай: пожелание` — изменить черновик.
- `/findimage описание` и `/image описание` — подобрать или создать иллюстрацию; `/noimage` — убрать её.
- `/schedule 09:00` — ежедневно готовить черновик; `/schedule off` — отключить. Публикация автоматически не выполняется.
- `/analytics` и `/status` — история публикаций и статус черновика.
- `/reset` — показать инструкцию сброса; `/reset confirm` — сбросить профиль и подключение ChatGPT.

Автоматический поиск использует Wikimedia Commons и выбирает изображения с лицензией CC0 или Public Domain. Для генерации иллюстраций нужен `OPENAI_API_KEY`. Имена моделей текстовых API настраиваются через `OPENAI_API_MODEL`, `GEMINI_MODEL`, `CLAUDE_MODEL` и `DEEPSEEK_MODEL`. История хранится в `vk_state.json`; секреты и авторизация остаются локальными в `.env` и `.auth`.

## Ограничения

- Сейчас VK-адаптер закрытый: управляет только один администратор, заданный в `VK_ADMIN_USER_ID`.
- `/analytics` показывает только публикации, созданные текущей версией адаптера; реакции и просмотры не считываются.
- Если VK API не подтвердил публикацию, сначала проверьте стену вручную. Черновик переводится в `needs_review`, чтобы избежать дубликата.
- Если для публикации фото VK отклонит загрузку, отправьте боту `/noimage` или подготовьте текстовый пост с фразой «только текст».
