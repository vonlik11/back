# Telegram AI-маркетолог

Рабочий Telegram-бот для одного тестового канала. Нужны Python 3.10+, Node.js 22.12+ и исходящие HTTPS-запросы. Python-библиотеки не нужны; Node использует `jose` для проверки OpenID Connect ID token.

## Настройка

1. В Telegram откройте `@BotFather`, выполните `/newbot`, задайте имя и скопируйте токен.
2. Добавьте бота в тестовый Telegram-канал как администратора с правом публикации сообщений.
3. Скопируйте `.env.example` в `.env` и вставьте токен бота и адрес канала (`@имя_канала` для публичного канала).
4. В PowerShell в папке `bot` выполните `npm install`.
5. Для первого входа выполните `npm run login`. Если предыдущая OAuth-регистрация была сделана на аккаунте без подписки, используйте `npm run login:new` — эта команда начнёт новую регистрацию. Откроется официальный вход OpenAI: выберите аккаунт с подпиской и явно разрешите AI-маркетологу использовать лимиты плана.
6. Запустите `python main.py`. Напишите боту `/start`; он покажет ваш chat ID. Остановите процесс, добавьте этот ID в `.env` как `TELEGRAM_ADMIN_CHAT_ID`, затем запустите снова.
7. Напишите боту задачу. Черновик появится в личном чате с кнопками одобрения и отклонения. Только одобрение публикует пост в канале. Для правок ответьте боту фразой `переделай: ...`.

Профиль тестовой компании редактируется в `company.json`. Контекст, черновики и состояние расписания хранятся в `state.json`. Для ежедневной подготовки черновика задайте `SCHEDULE_TIME` и `TIMEZONE`; задача отправляет материал на согласование и не публикует его сама. Токены ChatGPT зашифрованы Windows DPAPI текущего пользователя в `bot/.auth`, папка исключена из Git. Для нового компьютера выполните вход повторно.

## Запуск в Windows PowerShell

```powershell
Copy-Item .env.example .env
notepad .env
npm install
npm run login
python main.py
```

В первом запуске бота оставьте `TELEGRAM_ADMIN_CHAT_ID` пустым, напишите боту `/start`, запишите chat ID, остановите бота `Ctrl+C`, добавьте ID в `.env` и запустите снова.

## Ограничения хакатонной версии

Один клиент/оператор на экземпляр, текстовые публикации, polling (процесс должен быть запущен), JSON-файл без базы данных. Генерация картинок, веб-панель, несколько клиентов и аналитика пока не подключены. Доступность ChatGPT plan usage зависит от аккаунта, workspace и разрешений. Для коммерческого облачного SaaS нужна отдельная доступность от OpenAI. В OpenAI Docs описан путь для self-hosted VM: пройти OAuth локально и безопасно перенести защищённые учётные данные на VM; host-level usage attribution и remote revoke для такого переноса пока недоступны. См. [Self-hosted VMs](https://developers.openai.com/siwc/token-sharing-open-source/self-hosted-vms).
