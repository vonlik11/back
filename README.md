# Telegram AI-маркетолог

Сайт MARK-AI запускается вместе с ботом. Откройте папку `bot`, выполните `npm install` при первом запуске, затем `python main.py`. В браузере откройте [Маркетолог°](http://127.0.0.1:3000) и войдите с email и паролем, заданными при регистрации в боте. Вкладки используют общие профиль, черновики, расписание и аналитику.

На вкладке «Аналитика» и по команде `/analytics` доступны реакции по типам, наблюдаемые комментарии, нормировка на число подписчиков, первые реакции и комментарии, скорость реакций, время пика, half-life, длинный хвост и изменение аудитории через час и сутки. Добавьте бота администратором канала и привязанной группы обсуждений. Реакции Telegram может присылать с задержкой; комментарии считаются с момента добавления бота. Скорость и жизненный цикл поста накапливаются с включения сбора. Просмотры, пересылки и клики по обычным URL недоступны через Bot API. Оценка содержательности и спама использует простые правила по тексту, а не смысловой анализ. Счётчики аудитории опрашиваются примерно каждые 15 минут, поэтому значения около отметки публикации, +1 ч и +24 ч приблизительные. Вкладка обновляется автоматически, также можно нажать «Обновить».

Для открытия внутри Telegram настройте HTTPS-прокси на локальный порт сайта и укажите его адрес в `MINIAPP_URL` в `.env`. После перезапуска кнопка «Открыть Маркетолог°» появится в меню бота. При запуске из Telegram можно войти через Telegram вместо пароля. Локальный порт меняется через `MINIAPP_PORT`.

Telegram-бот с отдельным профилем и каналом для каждого пользователя. Нужны Python 3.10+, Node.js 22.12+ и исходящие HTTPS-запросы. Для входа ChatGPT Node использует библиотеку `jose`.

## Настройка владельцем бота

1. В Telegram откройте `@BotFather`, выполните `/newbot`, задайте имя и скопируйте токен.
2. Скопируйте `.env.example` в `.env` и вставьте токен бота. Имя бота задаётся через `@BotFather`.
3. В PowerShell в папке `bot` выполните `npm install`.
4. Запустите `python main.py`. Для локального подключения откройте Telegram Desktop на этом компьютере.
5. Подключите OpenAI API в меню бота, чтобы генерировать изображения за счёт API-проекта пользователя. Ключ защищён DPAPI и не передаётся в канал. Для генерации нужен доступ проекта к модели и API-баланс; подписка ChatGPT не даёт обхода API-оплаты. Поиск свободно лицензированных фото и загрузка своих изображений работают без ключа генерации. Не отправляйте API-ключ в GitHub.

## Настройка пользователем в Telegram

1. Откройте личный чат с ботом и отправьте `/start` или `/register`.
2. Введите email и придумайте отдельный пароль (12–128 символов), затем имя, компанию и описание её деятельности. Email пока не подтверждается ссылкой или кодом.
3. Добавьте бота в администраторы своего канала с правом публикации. Отправьте боту `@имя_канала`, публичную ссылку или числовой ID закрытого канала. Бот проверит право публикации у себя и у вас.
4. Регистрация завершится после проверки канала. Шаги регистрации идут по порядку: 1/6 email, 2/6 пароль, 3/6 имя, 4/6 компания, 5/6 описание, 6/6 канал. При изменении данных используются отдельные шаги 1/4–4/4. Учётная запись привязана к Telegram ID; email должен быть уникальным. Пароль хешируется PBKDF2-HMAC-SHA256 с индивидуальной солью, сообщение с паролем бот удаляет сразу. `/profile` показывает email и данные компании, пароль не отображает. Другие пользователи проходят регистрацию отдельно.
5. Выберите «Подключить ChatGPT» или «Подключить OpenAI API». Для ChatGPT откройте ссылку на компьютере с ботом и разрешите использование плана. Для OpenAI API создайте [ключ проекта](https://platform.openai.com/api-keys), проверьте [баланс API](https://platform.openai.com/account/billing/overview) и пришлите ключ отдельным сообщением в личный чат после команды `/api`. Бот удаляет сообщение и проверяет доступ к настроенной модели. У ключа должны быть права на чтение модели и создание Responses. Подключайте ключ только к экземпляру бота, которому доверяете.
6. После подключения отправьте `/post о нашем участии в хакатоне` или напишите задачу обычным сообщением. Черновик выходит в канал только после одобрения. `/ai` показывает варианты подключения, `/api` заменяет ключ, `/chatgpt` заново подключает план ChatGPT.

В меню `/start` и `/profile` есть кнопки «Подключить OpenAI API» и «Сбросить аккаунт». После подтверждения сброс удаляет профиль, сохранённые подключения, черновики и аналитику, затем запускает регистрацию заново. Опубликованные посты остаются в Telegram, а дневные лимиты обновляются по своему расписанию.

`/setup` меняет канал и описание компании. `/schedule 09:00` включает ежедневный черновик в часовом поясе владельца, `/schedule off` выключает его. После обновления профили с тестовой компанией нужно заново настроить через `/setup`. Если в старом `company.json` уже записана настоящая компания, бот перенесёт её вместе с прежними настройками канала.

Текст и поиск фото используют выбранное подключение: план ChatGPT или ключ проекта OpenAI. Для API-проекта используется быстрая модель `OPENAI_API_MODEL` (по умолчанию `gpt-5.4-mini`); модель входа ChatGPT задаётся отдельно через `CHATGPT_MODEL`. Ключи хранятся отдельно по Telegram ID и защищены DPAPI на Windows. Сгенерированные изображения оплачиваются API-проектом пользователя; общий `OPENAI_API_KEY` в `.env` остаётся доступен как ключ владельца сервиса. По умолчанию бот принимает до 5 текстовых запросов в день от пользователя и до 30 суммарно; лимиты изображений задаются через `DAILY_USER_IMAGE_LIMIT` и `DAILY_IMAGE_LIMIT`. Профили хранятся в `users.sqlite3`, черновики, незавершённая регистрация и история диалога — в `state.json`.

Для авторизации с другого устройства потребуется доступ OpenAI для удалённого приложения. [Документация Sign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source).

## Картинки к постам

Для новых постов бот пытается автоматически подобрать иллюстрацию. Приоритет: ваше фото, подходящий файл с Wikimedia Commons, затем генерация через подключённый API-проект, если поиск не дал результата. Без подключённого API бот оставляет текстовый черновик и предлагает поиск, генерацию или своё фото. Для текста без иллюстрации добавьте в запрос «только текст» или «без картинки». Публикация всегда требует одобрения.

Прикрепите фото и напишите задание в подписи — в пост попадёт это фото. Можно прислать фото отдельно: если есть черновик, фото заменит его иллюстрацию; иначе бот сохранит фото и дождётся задания. JPEG/PNG можно отправлять файлом до 10 МБ. Одно фото на пост; из альбома берётся первое. `/cancel` убирает отложенное фото. Содержимое фото не анализируется моделью: факты для текста нужно указать в подписи.

«Найти фото» или `/findimage описание` запускает новый поиск для текущего черновика. «Сгенерировать» или `/image описание` создаёт новую картинку через API. «Только текст» убирает фото. Правка текста сохраняет текущую иллюстрацию и ссылку на её источник.

Поиск использует публичный API Wikimedia Commons и выбирает JPEG/PNG с лицензиями Public Domain, CC0, CC BY и CC BY-SA по теме поста. Перед публикацией проверьте, что фото подходит. Для найденного изображения показываются источник, автор и лицензия; ссылка остаётся в опубликованном посте. Поиск не расходует дополнительные AI-запросы. При ошибке поиска или генерации текстовый черновик сохраняется.

Фото с подписью отправляется на согласование. После одобрения в канал отправляется ровно одно сообщение с тем же фото и текстом. Старые варианты больше нельзя опубликовать. Новые посты ограничены 900 символами для подписи; старый длинный черновик сначала нужно сократить. Если сервис изображений недоступен, предыдущий черновик сохраняется.

`OPENAI_IMAGE_MODEL` по умолчанию — `gpt-image-2.5-flare`, квадратный формат 1024 px, среднее качество. Старые значения `gpt-image-1` и `gpt-image-1.5` автоматически переключаются на эту быструю модель. Для API-ключа пользователя генерация изображений списывается с его API-проекта; подписка ChatGPT не заменяет баланс API. Поиск Commons и загрузка своего фото работают без API-ключа.

Документация: [ограничения Sign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations), [генерация изображений](https://developers.openai.com/api/docs/guides/image-generation).

## Запуск в Windows PowerShell

```powershell
Copy-Item .env.example .env
notepad .env
npm install
python main.py
```

## Ограничения хакатонной версии

`/analytics` показывает пять последних публикаций с реакциями, комментариями, нормированными долями и наблюдаемой динамикой. История до установки этой версии автоматически не импортируется.

Для диагностики выполните `python main.py --check`. Проверка показывает папку, источник токена, имя Telegram-бота и наличие webhook, не получает сообщения и не меняет настройки. Выполните её на обоих компьютерах: для разных ботов имена и ID должны отличаться. Переменная `TELEGRAM_BOT_TOKEN` в окружении имеет приоритет над `.env`. Ошибка 409 может означать другой процесс с тем же ботом или активный webhook.

Текст и изображения, один канал на пользователя, общий процесс бота и локальное хранилище JSON и SQLite. Сайт запускается вместе с ботом и использует те же профили, черновики и расписание. Во время генерации запросы других пользователей ожидают в очереди Telegram. Бот и сайт работают, пока запущен `python main.py`.

Проверки без отправки сообщений и без платных AI-запросов: `python -m unittest discover -s tests -v`.
