# Mark — Автономный AI-маркетолог для бизнеса (Telegram-бот + Веб-платформа для ПК и Mini App)

Платформа контент-маркетинга и ведения соцсетей по правилам технического задания (Fact-Grounding, Brand Voice, соответствие ФЗ «О рекламе», обязательное согласование публикаций и генерация иллюстраций к постам).

## 🎯 Режимы работы AI-чата Mark по ТЗ

1. **🎯 Пост + картинка в соцсети (`post`)** — создаёт готовый пост до 800 символов (для Telegram, VK или MAX) строго по фактам профиля компании без штампов и автоматически генерирует иллюстрацию к посту через API (`ROUTERAI_IMAGE_API_KEY`).
2. **📊 Аналитика (`analytics`)** — разбирает реальные показатели канала (реакции, ER, скорость отклика за 15/60 минут, доля содержательных комментариев) и строит матрицу гипотез по формуле «Если → То → За счёт чего».
3. **🔍 Разбор (`breakdown`)** — проводит аудит поста, оффера или креатива: сильные и слабые стороны, проверка тона бренда и соблюдения ст. 5 ФЗ-38 «О рекламе» + готовый улучшенный вариант.
4. **💡 Брейншторм (`brainstorm`)** — генерирует 10 тем и концепций с заголовками-хуками, опорой на факты бизнеса, идеей визуала и вовлекающим вопросом (CTA).
5. **🚀 Маркетинг (`marketing`)** — прорабатывает сегменты ЦА (JTBD), позиционирование, рубрикатор и кросс-платформенный контент-план для Telegram, VK и MAX.

## Исправления Mark

`python -m pip install -r requirements.txt` устанавливает зависимости текста. Node.js нужен только для сохранённых персональных ключей изображений. Запуск веб-студии без Telegram polling:
`python main.py --web-only`. Обычный `python main.py` запускает бота и студию.
В Windows при отсутствии Python/Node в PATH используйте полные пути к установленным программам.

Создайте аккаунт Mark (email и пароль от 12 символов). После регистрации подключите личный OpenAI API в Telegram командой `/api`: отправьте ключ отдельным сообщением, бот удалит его перед проверкой и сохранит в закрытом хранилище устройства. Windows использует DPAPI; Linux/macOS — AES-GCM и локальный файл ключа с ограниченными правами. Личный ключ используется для текста и генерации изображений. Если личного ключа нет, сервер может использовать общий RouterAI ключ из `.env`.
Сессии хранятся в SQLite; cookie HttpOnly, SameSite=Strict. За HTTPS установите COOKIE_SECURE=1.
Профиль, черновики и история изолированы по аккаунту. X-Chat-Id не даёт доступа к другим аккаунтам.

Изображения: при подключённом личном ключе — через OpenAI API; без него может использоваться Recraft через RouterAI.
Общий ключ изображений — `ROUTERAI_IMAGE_API_KEY`, при отсутствии используется `ROUTERAI_API_KEY`.
Модель: `ROUTERAI_IMAGE_MODEL=black-forest-labs/flux-3-image`.
Формат: `ROUTERAI_IMAGE_ASPECT_RATIO=1:1` (также 4:3, 3:4, 16:9, 9:16, auto).
Ответ base64 декодируется; WebP преобразуется в PNG библиотекой Pillow для совместимости с Telegram.
Старые персональные ключи SpeShu не используются. Ключи изображений меняются на сервере.
Платная генерация не повторяется автоматически при таймауте.

Интеграции публикации VK/MAX, загрузка документов и автоматический мониторинг конкурентов
пока не реализованы. UI сообщает об этом, а не показывает фиктивный результат.
Аналитика отображает только собранные события Telegram. Проверка фактов и рекламных
формулировок остаётся частью согласования пользователем; выдуманных оценок больше нет.

## RouterAI Python module

`routerai_client.py` exposes `brainstorm(topic)`, `write_post(idea, tone)` and `analyze(data_text)`.
Install Python dependencies with `pip install -r requirements.txt`, set `ROUTERAI_API_KEY` in `.env`,
and run `python examples/routerai_demo.py`. The model defaults to `openai/gpt-6-luna`;
set `MODEL_NAME=openai/gpt-6-terra` to switch models without changing the code. Requests
use RouterAI's OpenAI-compatible Chat Completions endpoint, `reasoning_effort=low`, and
`max_tokens=2400` (override with `ROUTERAI_MAX_TOKENS`). The demo sends three real API requests and may incur usage charges.

## Общий AI и память компании

Оба чата и студия постов используют личный OpenAI API пользователя, подключённый через `/api`, либо общий RouterAI ключ сервера.
Параметры `.env`:

```dotenv
ROUTERAI_API_KEY=<необязательный общий ключ администратора>
MODEL_NAME=openai/gpt-6-luna
ROUTERAI_MAX_TOKENS=2400
```

Для Terra замените только `MODEL_NAME=openai/gpt-6-terra` и перезапустите Mark.
Существующие ограничения `DAILY_AI_LIMIT` и `DAILY_USER_LIMIT` действуют на запросы приложения;
один ответ может включать несколько оплачиваемых обращений к модели для инструментов.
Ключ не возвращается браузеру, не отправляется в Telegram и не хранится отдельно для пользователей.
Протокол инструментов: https://routerai.ru/docs/guides/overview/parameters.

Факты из диалога модель сохраняет в `company_memory` в `users.sqlite3`. Исправления обновляют
факт по имени. Память видна в профиле сайта и по `/memory` в боте. Можно написать «запомни…»,
«исправь цену…», «забудь…». Полная история новых диалогов сохраняется в `conversation_messages`;
в контекст идут последние сообщения и факты, более ранние сообщения доступны модели поиском.
Старая сохранившаяся история импортируется при первом запросе. Уже обрезанные старой версией сообщения восстановить нельзя.
Лимит фактов — 60 000 символов на компанию, до 2000 на один факт: это долговременная память,
но не обещание безошибочно запомнить каждое слово. Сохранение зависит от вызова инструмента моделью.
Очистка чата удаляет историю, оставляя факты; сброс аккаунта удаляет и факты, и историю.
Профиль компании также передаётся при каждом запросе. При арифметике модель использует ограниченный калькулятор.

Для общей памяти сайта и Telegram нужен **один аккаунт Mark**: откройте сайт как Mini App
из бота либо войдите с email/паролем, заданными для этого Telegram-аккаунта. Отдельно созданный
веб-аккаунт — отдельная компания; данные разных аккаунтов не объединяются автоматически.

Windows без Python в PATH:

```powershell
& "C:\Users\Вадим\AppData\Local\Python\bin\python.exe" -m pip install -r requirements.txt
& "C:\Users\Вадим\AppData\Local\Python\bin\python.exe" main.py
```

Локальные тесты: `python -m unittest discover -s tests -p "test_*.py"` и `node tests/test_front.cjs`.
Реальная проверка RouterAI: `python examples/routerai_smoke.py` — временная база, тестовые данные,
несколько оплачиваемых запросов; сообщения и посты в Telegram не отправляются.
